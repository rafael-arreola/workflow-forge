# workflow-forge-engine

Workflow preparation, schema validation, coordination, bounded execution and recovery through protocol-defined ports. Most host applications should use the workflow-forge facade.

Part of [Workflow Forge](https://github.com/rafael-arreola/workflow-forge).
See the [integration guide](https://github.com/rafael-arreola/workflow-forge/blob/main/docs/EMBEDDING.md)
and [API documentation](https://docs.rs/workflow-forge-engine).
