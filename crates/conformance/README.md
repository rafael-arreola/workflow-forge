# workflow-forge-conformance

Reusable behavioral checks for implementations of Workflow Forge infrastructure contracts. Run these checks alongside provider-specific tests for failures, durability and concurrency.

Part of [Workflow Forge](https://github.com/rafael-arreola/workflow-forge).
See the [integration guide](https://github.com/rafael-arreola/workflow-forge/blob/main/docs/EMBEDDING.md)
and [API documentation](https://docs.rs/workflow-forge-conformance).
