# workflow-forge

A Rust-only workflow engine embedded in your application. Compose a runtime once, prepare JSON workflows, execute them with host cancellation and shut down explicitly. No server or remote client is required.

Part of [Workflow Forge](https://github.com/rafael-arreola/workflow-forge).
See the [integration guide](https://github.com/rafael-arreola/workflow-forge/blob/main/docs/EMBEDDING.md)
and [API documentation](https://docs.rs/workflow-forge).
