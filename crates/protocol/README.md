# workflow-forge-protocol

Public types and traits for operations, execution stores, artifacts, secrets, retries and workflow definitions. Extension crates should depend on this crate instead of engine internals.

Part of [Workflow Forge](https://github.com/rafael-arreola/workflow-forge).
See the [integration guide](https://github.com/rafael-arreola/workflow-forge/blob/main/docs/EMBEDDING.md)
and [API documentation](https://docs.rs/workflow-forge-protocol).
