# workflow-forge-modules

Official memory providers and data operations, with optional SQLite persistence and outbound HTTP, file and CSV integrations. Features expose constructors; the host explicitly selects providers and registers operation bundles.

Part of [Workflow Forge](https://github.com/rafael-arreola/workflow-forge).
See the [integration guide](https://github.com/rafael-arreola/workflow-forge/blob/main/docs/EMBEDDING.md)
and [API documentation](https://docs.rs/workflow-forge-modules).
